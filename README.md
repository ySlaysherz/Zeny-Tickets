# 🎟 Zeny Tickets

### 📌 Sobre o plugin

Este plugin foi desenvolvido para o servidor Zeny SMP com o intuito de:

1. Resolver: Acumulo de gambiarras geradas na tentativa de executar comandos ou ações usando itens.
2. Melhorar: Compatibilidade, eficiência e segurança.
3. Adicionar: Possibilidades para escalar em execuções mais bem planejadas e seguras.

### ⚙️ Compatibilidade
 Versão do Minecraft: 1.21.11
 API: Paper
 Java: 17+
 
# 🚀 Funcionalidades

### 🎮 Sistemas
- Ao jogador interagir com o ambiente segurando um ticket em suas maos, consumirá o ticket e executará um comando personalizado para o ticket consumido.

- Observações:
  - Comandos apenas serão executados caso já existam antes;

### ⌨️ Comandos

- /ticket id
- /tickets
- /criarticket vip duracao

🔐 Permissões

zenytickets.admin	Acesso total
zenytickets.use	Uso básico
     
# ⚙️ Instalação
1. Baixe o .jar
2. Coloque na pasta /plugins
3. Inicie o servidor ou use plugins que permite inicialização personalizada por exemplo o PlugmanX

Pronto!

# 🧪 Como testar
