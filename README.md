# 🎟 Zeny Tickets

### 📌 Sobre o plugin

Este plugin foi desenvolvido para servidores Minecraft com o objetivo de:

1. Resolver: Acumulo de gambiarras geradas na tentativa de executar comandos ou ações usando itens.
2. Melhorar: Compatibilidade, eficiência e segurança.
3. Adicionar: Possibilidades para escalar em execuções mais bem planejadas e seguras.

### ⚙️ Compatibilidade
 Versão do Minecraft: 1.21.11
 API: Paper
 Java: 17+
 
# 🚀 Funcionalidades

### 🎮 Sistemas
- Ao jogador interagir com o ambiente segurando um ticket em suas maos, consumirá o ticket e executará uma ação, evento ou comando personalizado para o ticket consumido.

- Observações:
  - Comandos apenas serão executados caso já existam antes;
  - Eventos são os que o paper executa; Exemplo: PlayerJoinEvent
  - Ações são uma lista ou apenas uma execução de ações personalizadas pelo criador do ticket; Exemplo: ao consumir o ticket irá executar um comando, irá receber uma cobblestone e evoluirá de nível.

- Lista de ações possíveis abaixo.
  - comando
  - Evento
  - Ação

### ⌨️ Comandos

- /ticket "comando" "nome_do_comando" "nome_do_jogador" "(opcional) mensagem ao consumir ticket"
- /ticket "evento" "nome_do_evento" "nome_do_jogador" "(opcional) mensagem ao consumir ticket"
- /ticket "acao" "nome_da_acao" "nome_do_jogador" "(opcional) mensagem ao consumir ticket"


🔐 Permissões

zenytickets.admin	Acesso total
zenytickets.use	Uso básico
     
# ⚙️ Instalação
1. Baixe o .jar
2. Coloque na pasta /plugins
3. Inicie o servidor ou use plugins que permite inicialização personalizada por exemplo o PlugmanX

Pronto!
